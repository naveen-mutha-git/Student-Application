# Student Application System

A full-stack student management web application developed using Spring Boot, Thymeleaf, and MySQL.  
The system helps educational institutions manage student records, courses, grades, notifications, and profiles through a responsive and user-friendly dashboard.

---

## 🚀 Features

- Student Registration & Login  
- Student Profile Management  
- Course Management System  
- Grade Management  
- Notification Management  
- Responsive Dashboard UI  
- CRUD Operations for Student Data  
- MVC Architecture using Spring Boot  
- Database Integration with MySQL  
- Server-Side Rendering using Thymeleaf  
- Form Validation & Error Handling  
- Clean and Organized Project Structure  

---

## 🛠️ Tech Stack

### Backend
- **Java 17** – Core programming language  
- **Spring Boot** – Backend framework  
- **Spring MVC** – MVC architecture  
- **Spring Data JPA** – Database operations  
- **Hibernate** – ORM framework  

### Frontend
- **HTML5** – Structure and content  
- **CSS3** – Styling and layouts  
- **Bootstrap 5** – Responsive design  
- **JavaScript** – Client-side interactivity  
- **Thymeleaf** – Dynamic template rendering  

### Database
- **MySQL** – Relational database management system  

### Development Tools
- **Spring Tool Suite (STS)**  
- **VS Code**  
- **Git & GitHub**
